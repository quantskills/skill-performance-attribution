# 三层归因总览与方法选型

> 这是本 skill 的心脏文档：三层归因分别解决什么问题、公式、输出、对账方式。
> 与 `skill-risk-model` 的边界：risk-model 做**风险**归因（波动从哪来），本 skill 做**收益**归因（收益从哪来）。

## 三层结构

```
组合收益
├─ 层1 Alpha/Beta/择时 —— 市场 vs 组合 vs 主动
├─ 层2 Brinson —— 行业/资产维度的 配置 + 选择 + 交互
└─ 层3 因子收益归因 —— 风格/行业因子暴露×因子收益 + Alpha 残差
```

| 层 | 问题 | 方法 | 输出 | 对账 |
|---|---|---|---|---|
| 1 | 组合收益多少来自市场、多少来自主动？ | CAPM 式 OLS 回归 + Treynor-Mazuy | β、Jensen's Alpha、择时项 | `α + β·R_m` 拟合值 vs 实际 |
| 2 | 超额来自行业配置还是个股选择？ | Brinson-Fachler | 每行业 配置/选择/交互 | 三者和 ≈ 组合超额 |
| 3 | 超额来自哪个因子暴露？Alpha 还剩多少？ | 多因子模型 + 截面 WLS | 逐因子/逐行业贡献 + Alpha 残差 | Σ贡献 + Alpha ≈ 实际超额 |

## 选型规则

- **默认三层全算**（`attribution_scope=all`）。
- 缺行业映射 → 层2 退化为全市场一层（只剩选择效应），并在报告标注。
- 缺因子暴露/因子收益 → 层3 降级为 INFO（建议补材料），不编造暴露硬算。
- 基准与策略错配（如 A 股多头配无风险利率）→ 层1 降级提示。

## 口径声明（计算前必须确认）

1. **基准**：可比宽基（沪深300 / 中证500 / 中证1000）或自定义；超额 = 组合 − 基准（同区间、同频率、含成本）。
2. **行业映射**：申万一级 / 中信一级等；一个 symbol 只属一个行业。
3. **因子模型**：风格因子（市值/动量/反转/波动等）+ 行业哑变量；暴露为组合 vs 基准的差。
4. **成本**：归因用净收益（成本已扣）还是毛收益需声明，两套不可混。
5. **收益频率**：日频对齐，节假日两端补齐或截断。

## 对账（reconciliation）

每层输出必须附对账数字：
- 层2：`Σ(配置+选择+交互) − 超额` 的残差 ≈ 0（< 1e-6）
- 层3：`Σ_k(贡献_k) + Alpha残差 − 超额` 的残差 ≈ 0

对不上 → 报告标记「⚠️ 未对账」，并列出残差来源（缺数据 / 口径不一致）。
